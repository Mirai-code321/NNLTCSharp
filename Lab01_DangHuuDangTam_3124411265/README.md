## 🧠 Kết quả học tập

- Chuyển yêu cầu thành đầu vào, các bước xử lý và đầu ra rõ ràng.
- Chọn cấu trúc điều khiển phù hợp; hiểu vai trò của chỉ số và giới hạn vòng lặp.
- Tách logic khỏi nhập xuất để dễ kiểm tra bằng xUnit.
- Đối chiếu kết quả với test có sẵn, đặc biệt ở các tình huống biên.

## ▶️ Chạy thử

Từ thư mục gốc repository:

```powershell
dotnet run --project "Lab01_DangHuuDangTam_3124411265/Buoi01/Buoi1_BaiTapCoBan/Bai1_InNhan/Bai1_InNhan.csproj"
dotnet test "Lab01_DangHuuDangTam_3124411265/Buoi01/Buoi1_BaiTapCoBan/Bai1_InNhanTest/Bai1_InNhanTest.csproj"
```

Các thư mục `BaiTapCoBan` và `BaiTapNangCao` phân nhóm độ khó. Project chứa `Test` là bộ kiểm thử, không phải chương trình console cần chọn để chạy.
