## 🧠 Kết quả học tập

- Hiểu mô hình lập trình theo sự kiện: người dùng thao tác, chương trình xử lý và cập nhật giao diện.
- Sử dụng form và các control nhập liệu, lựa chọn, nút bấm, thông báo.
- Chuyển dữ liệu dạng văn bản sang kiểu số phù hợp và phản hồi khi dữ liệu chưa hợp lệ.
- Tách các bước tính toán để trình xử lý sự kiện dễ đọc hơn.

## ▶️ Chạy thử

Cần Windows và .NET SDK hỗ trợ WinForms. Từ thư mục gốc:

```powershell
dotnet run --project "Lab04_WinFormBasic_DangHuuDangTam_3124411265/TH4c/Bai01_PhepTinh/Bai01_PhepTinh.csproj"
```

Có thể mở `.csproj` trong Visual Studio với workload **.NET desktop development** rồi chạy bằng F5. Thử dữ liệu đúng, ô trống, dữ liệu không phải số và các điều kiện đặc biệt của bài toán.
